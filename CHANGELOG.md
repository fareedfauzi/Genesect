# Changelog

## 1.0.0

- Independent Extended package, action namespace, configuration and IDB storage.
- Professional shared UI foundation and redesigned main workspace.
- Provider profiles, validation, diagnostics, retry and request lifecycle controls.
- Previewed, validated and auditable AI changes.
- Shared bulk workbench with pause, resume, retry, estimates and session state.
- Recoverable Deep Analyzer with atomic identity-bound checkpoints and multi-format reports.
- Per-function and chain chat improvements plus read-only-by-default agent tooling.
- Hardened Hex Viewer, xrefs, FLOSS and vftable utilities.
- Removed the experimental Pseudocode Control-Flow Graph utility.
- Non-destructive migration from classic PseudoNote.
- Task-oriented right-click submenus with clearer action names, restrained separators, and semantic SVG icons.
